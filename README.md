# Network Kit

**Network Kit** is a local-first macOS workspace for managing the relationship-driven job search: companies, people, job opportunities, outreach, meetings, application documents, and follow-up in one place.

This is the **public binary release repository** for Network Kit. The application source code is not published here.

## Current Release

The next release is:

**Network Kit Castor V1.0**

The macOS Apple silicon build will be attached to the corresponding GitHub Release once final packaging is complete.

## What Network Kit Does

- Keep a working database of people and companies.
- Pin and sort the contacts and companies that matter now.
- Review saved company careers pages on a repeatable cadence.
- Capture individual job postings by URL, with automatic metadata/description extraction where supported and manual entry when needed.
- Maintain a curated Career Feed of jobs you intentionally saved.
- Promote promising jobs into Opportunity workspaces.
- Connect people, outreach, meetings, notes, documents, application status, and next steps to each pursuit.
- Create and tailor resumes and cover letters with AI handoff workflows.
- Store working data locally on your Mac.

## macOS Security

Release notes will state the signing/notarization status of each build. If a build is not Apple-notarized, macOS may require additional confirmation before first launch.

## Privacy

Network Kit is designed as a local-first application. Release builds do not include the developer's personal workspace database, contacts, application records, or credentials.

Always keep your own backups of important Network Kit data.

## Source Code

The source code for Network Kit is private and is **not distributed through this repository**.
